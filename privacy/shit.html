Hnode는 이 앱의 개인정보를 다음과 같이 처리합니다. 이 방침의 기본 설명은 Google Play 배포판에 적용되며, 별도 APK 배포판의 차이는 아래에 표시합니다.

1. 앱이 처리하는 정보와 목적

앱은 카메라 셔터음 설정을 변경하기 위해 이 기기의 무선 디버깅 서비스에 연결합니다. 사진·영상·음성·연락처·정확한 위치·광고 ID를 읽거나 수집하지 않습니다. 회원 가입, 광고, 사용 분석 SDK를 제공하지 않습니다.

  • 페어링 코드: 사용자가 입력한 6자리 숫자를 기기 연결 인증에 일시적으로 사용합니다. 앱 저장소에 영구 저장하지 않습니다.
  • 연결 인증 키 및 인증서: 반복 연결을 위해 앱 전용 저장소에 저장합니다. 개발자 서버에 전송하지 않습니다.
  • 연결 주소·포트·연결 상태 및 설정값: 무선 디버깅 탐색, 연결, 설정 변경과 오류 안내에 사용합니다. 연결 상태 일부를 앱 전용 저장소에 보관합니다.
  • 진단 로그: 기기의 Android 로그에 연결 진행 상태와 오류를 기록할 수 있습니다. 로그를 개발자 서버로 자동 업로드하지 않습니다.

2. 외부 전송과 제3자 제공

Google Play 배포판은 앱 내부에서 처리하는 위 정보를 개발자 서버에 수집·전송하거나 판매하지 않습니다. 사용자 요청에 따른 연결 인증 정보와 설정 변경 명령은 기기 자체의 Android 디버깅 서비스에 전달됩니다. Wi-Fi 서비스 탐색은 로컬 네트워크를 이용하며 외부 분석 서버를 이용하지 않습니다.

사용자가 Play 스토어 페이지나 문의 이메일을 열면 Google Play 또는 이메일 서비스가 해당 요청을 처리하며 각 서비스의 개인정보처리방침이 적용됩니다. 문의를 보낼 경우 이메일 주소와 사용자가 제공한 문의 내용을 문의 응답과 문제 해결에 사용합니다.

3. 별도 APK 배포판의 업데이트

GitHub 등에서 직접 설치한 별도 APK 배포판은 업데이트 확인 및 다운로드를 위해 GitHub 서버에 연결합니다. 이 경우 GitHub에 IP 주소와 일반적인 HTTP 요청 정보가 전달될 수 있으며 GitHub의 개인정보처리방침이 적용됩니다. Google Play 배포판은 이 업데이트 기능을 사용하지 않습니다.

4. 보관 기간과 삭제

연결 인증 키와 앱 설정은 앱을 사용하는 동안 앱 전용 저장소에 보관합니다. Android 설정에서 앱 데이터 삭제 또는 앱 제거를 하면 앱의 저장 데이터가 삭제됩니다. 무선 디버깅 설정의 페어링된 기기 목록에 남은 연결은 해당 화면에서 직접 삭제할 수 있습니다. 앱 제거만으로 변경된 셔터음 설정이나 이미 부여된 시스템 설정이 원래대로 돌아오는 것은 아닙니다. 필요하면 제거 전에 앱에서 유음으로 되돌려 주세요.

문의 이메일은 문의 처리 목적이 달성된 후 삭제합니다. 법령상 보관이 필요한 경우에는 해당 기간 동안 보관합니다. 기기의 Android 진단 로그 보관은 운영체제 정책에 따릅니다.

5. 보호 조치와 이용자 선택

앱 전용 저장소와 Android의 앱 접근 제한을 사용하며 무선 디버깅 인증에는 암호화된 연결을 사용합니다. Google Play 배포판에서는 연결 키와 설정이 Android 클라우드 백업 및 기기 이전에 포함되지 않도록 설정합니다. 알림 권한과 설정 변경 동의는 사용자가 선택할 수 있으며, 기기 설정에서 권한을 변경하거나 앱 데이터를 삭제할 수 있습니다.
